# Лабораторная №2 — CINEFLIX
Адаптивный кинолендинг в стилистике Netflix: Grid, Flexbox, mobile first, точки 768/1200 px, меню и форма без JS. Фильмы вымышленные, графика локальная; для запуска откройте `index.html`.
Авторская композиция: макет Figma не использовался. Для полного соответствия заданию требуется согласовать самостоятельный дизайн либо сверстать разрешённый макет и указать ссылку на него.
